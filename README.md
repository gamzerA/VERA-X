# VERA-X

Industrial vision. Traceable inspection evidence.

VERA-X의 제품 소개 웹사이트입니다. 산업 제품 비주얼, 설명용 워크플로와 접근 가능한 인터랙션을 포함합니다.

## 미리보기

```sh
python3 -m http.server 8085 --bind 127.0.0.1 --directory site
```

이 컴퓨터에서 http://127.0.0.1:8085 를 엽니다. 공개 배포 주소가 아닙니다. 별도 빌드나 모델 설치는 필요하지 않습니다.

## 포함 범위

- 정적 HTML / CSS / JavaScript
- 제품 소개 이미지 및 자체 제공 폰트
- 설명용 워크플로, Pause/Play, 키보드 탐색, 모션 감소 대응

이 저장소는 소개 사이트만 제공합니다. 실제 검사 서비스, Python API, 모델, 데이터셋, 실험 결과, 연구 방법과 논문 자료는 포함하지 않습니다. CTA는 설명 섹션으로 이동하며 실제 검사를 실행하지 않습니다.

Hero는 산업 제품을 표현한 생성 이미지이고 실제 검사 결과가 아닙니다. 워크플로는 제품 구조를 설명하는 시각화입니다.
